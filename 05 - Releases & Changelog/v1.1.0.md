## 🚀 Key Improvements in v1.1.0

### 1. Apple HIG Preferences Architecture (Faculty Defaults)
- Redesigned the **Faculty Defaults** configuration tab into an authentic **Apple Human Interface Guidelines Inset Grouped List** (`.apple-hig-group`).
- **Themed Squircle Icon Tiles**: Added macOS-style glyph tiles with subtle tinted backgrounds (👤 Blue for Instructor, 🏛️ Emerald for College, 🗓️ Amber for Semester & Term).
- **Clear Typographic Hierarchy**: Upgraded rows with semibold primary labels and secondary descriptive caption subtitles.
- **Apple-Styled Right-Aligned Inputs**: Clean inset controls (`.apple-hig-input`) with smooth emerald focus rings and responsive full-width vertical collapse on mobile devices (`<= 680px`).

### 2. macOS Quick Look Document Header Live Preview
- Integrated a live document header simulation card (`.apple-hig-preview-card`) featuring an authentic Cavite State University masthead.
- **Real-Time Live Sync**: Synchronized typography with an active `• LIVE SYNC` badge that updates in real time as the user types into instructor, college, or semester defaults.
- **Vertical Space Harmony**: Fills the uniform modal body purposefully, providing instant visual feedback on how metadata will format on generated CEIT Forms and grading sheets.

### 3. Uniform Modal Geometry & Elastic Components
- Fixed dialog height jumping across all 6 configuration sections (Subject Prefixes, Lab Courses, Degree Aliases, Roster Keywords, Faculty Defaults, Custom Forms) with a stable, centered bounding box (`width: min(920px, calc(100vw - 32px))`, `height: min(680px, 88vh)`).
- **Elastic Inner Components**: Removed inline max-height caps from Degree Aliases and Roster Keywords, allowing table wrappers and tag clouds to flex-grow smoothly down to the footer action bar.

### 4. Dynamic Step 4 (Dates) Stepper Chip
- Replaced static readiness evaluation with dynamic boundary checking: Step 4 remains in a neutral dot state (`•`) until `startDate` and `endDate` boundaries are supplied or selected via semester presets.
- Clear action immediately resets the chip to neutral, eliminating false positive readiness signals.

### 5. Multi-Breakpoint Responsive Adaptation
- **Tablet Adaptation (`<= 820px`)**: Segmented navigation tabs seamlessly adapt into a 3x2 grid with comfortable touch targets.
- **Mobile Adaptation (`<= 480px`)**: Tabs transform into a 2x3 grid, multi-column inputs collapse to single-column flows, and the modal footer stacks utility actions above primary dialog buttons.
- **Short Viewports (`<= 640px height`)**: The modal dialog automatically caps at `94vh` with reduced backdrop padding (`8px`), ensuring all controls remain visible and scrollable.

### 6. Self-Analyzing Dynamic Template Engine & OpenXML Grid Invariance
- **Deterministic Offline Introspection**: Replaced static hardcoded table/row/column offsets with `DeterministicTemplateAnalyzer`, analyzing `.docx` OpenXML trees and `.xlsx` worksheets in under 20ms without LibreOffice or Microsoft Word runtime dependencies.
- **2D Virtual Grid Normalization (`DocxGridTable`)**: Maps complex tables with `<w:gridSpan>` and `<w:vMerge>` into an invariant 2D virtual coordinate grid, routing cell mutations to root cells and preventing duplicate cell writes.
- **Semantic Slot Anchoring**: Automatically locates institutional and course metadata fields via four resilient anchoring heuristics: `cell_right`, `cell_below`, `colon_value`, and `placeholder`.
- **Universal Dynamic Renderer (`DynamicDocumentRenderer`)**: Dynamically injects student records, scales long names with a 3-tier font size ladder (`<=30` -> 8pt, `31-35` -> 7pt, `>35` -> 6pt), preserves run-level styling, cell shading, and `<w:numPr>` list numbering across arbitrary template layouts.
- **Verification & Resilience Harness**: Backed by 100% golden-master parity (`test_golden_parity.py`), deterministic analyzer tests (`test_deterministic_template_analyzer.py`), and perturbation resilience verification (`test_dynamic_renderer_resilience.py`).
