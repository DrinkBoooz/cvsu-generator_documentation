## 🚀 Key Improvements in v1.0.1

### 1. Interactive 6-Step Visual Stepper Bar & Floating Dock
- Integrated `#workflowStepper` bar with interactive step chips (`#chipStep1` &ndash; `#chipStep6`) and animated progression connectors (`#connector1to2` &ndash; `#connector5to6`).
- Fixed UI synchronization bugs in the workflow stepper and introduced a floating control dock (Commit `6cfb685`).
- Native Windows OLE drag-and-drop (`IDropTarget`) via `pythonnet` bypassing the Chromium webview (Commit `c9e2c00`).
- Real-time step status synchronization based on file ingestion, class detection, and generation phases.

### 2. Graceful Thread Cancellation Engine
- Introduced `cancel_generation` API binding with thread-safe `_cancel_event`.
- Introduced the `process_all` dual-pass cancellation engine and explicit JavaScript evaluation callbacks for progress telemetry (Commit `af78ff9`).
- Faculty members can cancel long-running generation jobs midway without corrupting output directories or causing orphaned file locks.
- Real-time stopwatch displays elapsed processing time and cancellation feedback.

### 3. Accessible Toast Notification System
- Replaced disruptive alert dialogs with floating `#toastContainer` notifications (`success`, `error`, `info`).
- Screen reader accessible via `role="status"` and `aria-live="polite"`.

### 4. Accessibility & UI Enhancements (WCAG 2.1 AA)
- Added skip-link navigation (`#mainContent`).
- Complete keyboard focus management across file dialogs, drawers, and modal windows.
- Accessible documentation drawer (`helpDrawer`) providing instant in-app guidance.
- Enhanced high-contrast color palette for both Dark and Light themes.

### 5. Playwright End-to-End Test Suite & Strict Signing
- Introduced runtime Playwright tests bundled with the `axe-core` accessibility engine (Commit `38ae972`).
- Tightened axe-core violation policies and delivered the digitally signed v1.0.1 executable, explaining the strict UI testing constraints and the corresponding Authenticode metadata in `file_version_info.txt` (Commit `c2d467e`).
- Comprehensive automated UI testing verifying drag-and-drop file ingestion, stepper state progressions, theme switching performance, and roster mapping edge cases.
